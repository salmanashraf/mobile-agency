# Game Development Prompts

Standalone prompts for Unity and Unreal Engine development tasks.

## Index

| File | Purpose |
|---|---|
| [shader-from-reference.md](shader-from-reference.md) | Generate a Unity shader matching a visual reference description |
| [blueprint-to-cpp.md](blueprint-to-cpp.md) | Convert an Unreal Blueprint description to C++ |
| [game-object-architecture.md](game-object-architecture.md) | Design a GameObject / Actor component architecture |
| [game-balance.md](game-balance.md) | Generate a data-driven balance spreadsheet for game stats |
| [level-design-review.md](level-design-review.md) | Review a level design brief for pacing and player experience |

## Usage

```
cat prompts/game-dev/shader-from-reference.md
# Paste into your LLM session with your effect description
```
