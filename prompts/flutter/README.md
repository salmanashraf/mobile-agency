# Flutter Prompts

Standalone prompts for Flutter/Dart development tasks.

## Index

| File | Purpose |
|---|---|
| [widget-from-design.md](widget-from-design.md) | Generate a Flutter widget from a Figma / wireframe description |
| [riverpod-migration.md](riverpod-migration.md) | Migrate Provider code to Riverpod |
| [test-golden.md](test-golden.md) | Generate a golden test for a Flutter widget |
| [performance-audit.md](performance-audit.md) | Audit a Flutter widget tree for performance issues |

## Usage

```
cat prompts/flutter/widget-from-design.md
# Paste into your LLM session with your design description
```
