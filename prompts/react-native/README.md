# React Native Prompts

Standalone prompts for React Native / TypeScript development tasks.

## Index

| File | Purpose |
|---|---|
| [component-audit.md](component-audit.md) | Quick performance audit of a single RN component |
| [new-arch-migration.md](new-arch-migration.md) | Guide migration from Old Architecture to New Architecture |
| [navigation-setup.md](navigation-setup.md) | Generate React Navigation v7 stack configuration |
| [e2e-test.md](e2e-test.md) | Generate a Detox E2E test for a user flow |

## Usage

```
cat prompts/react-native/component-audit.md
# Paste into Claude Code or another LLM with your component
```
