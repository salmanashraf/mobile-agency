# Android Prompts

Standalone prompts for Android development tasks. Each file is a ready-to-use prompt — paste the content into your LLM of choice along with your code or question.

## Index

| File | Purpose |
|---|---|
| [explain-flow.md](explain-flow.md) | Explain a Kotlin Flow chain in plain English |
| [generate-unit-test.md](generate-unit-test.md) | Generate a JUnit + MockK unit test for a given class |
| [migration-guide.md](migration-guide.md) | Generate a step-by-step migration plan (e.g., LiveData → StateFlow) |
| [compose-layout.md](compose-layout.md) | Generate a Jetpack Compose layout from a wireframe description |
| [gradle-dependency-audit.md](gradle-dependency-audit.md) | Audit a build.gradle.kts for outdated or conflicting dependencies |

## Usage

```
cat prompts/android/explain-flow.md
# Copy the prompt, paste into Claude or another LLM, add your code
```
