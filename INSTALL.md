# Install Mobile AI Agents

For a beginner-friendly walkthrough, see the full [Installation Guide](docs/installation.md).

Quick install:

```bash
npx mobile-ai-agents install
```

Common options:

```bash
npx mobile-ai-agents install --tool cursor
npx mobile-ai-agents install --tool codex
npx mobile-ai-agents install --platform flutter --tool cursor
npx mobile-ai-agents install --tool all
```

The guide explains which command to use for Claude Code, Cursor, Windsurf, GitHub Copilot, and Codex.
