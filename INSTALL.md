# Install Mobile Agency

For a beginner-friendly walkthrough, see the full [Installation Guide](docs/installation.md).

Quick install:

```bash
npx mobile-agency install
```

Common options:

```bash
npx mobile-agency install --tool cursor
npx mobile-agency install --tool codex
npx mobile-agency install --platform flutter --tool cursor
npx mobile-agency install --tool all
```

The guide explains which command to use for Claude Code, Cursor, Windsurf, GitHub Copilot, and Codex.
